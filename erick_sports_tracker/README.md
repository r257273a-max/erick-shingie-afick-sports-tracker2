# Erick Shingie Afick Sports Tracker

Offline Android application implementing the supplied Sports Team Player Management System proposal.

## Features
- Local JSON file storage; no server, login, or internet required.
- CRUD for player profiles.
- Search and position filtering.
- Fitness, performance and attendance scores.
- Mathematical efficiency metric and injury status/history.
- Analytics summary.
- Input validation.
- CSV export.
- Designed for 500+ local profiles.

## Build
Requires Android Studio or a cloud Android build environment with Android SDK 35 and JDK 17/21.
Open this folder as an Android Studio project and choose **Build > Build APK(s)**. The APK will be under `app/build/outputs/apk/debug/`.

Application ID: `com.erickafick.sportstracker`
Version: 1.0.0
